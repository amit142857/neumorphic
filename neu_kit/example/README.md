# Flutter Neumorphic UI Kit — Showcase App

An interactive, multi-screen catalog and live lighting playground showcasing all components from the **Flutter Neumorphic UI Kit**.

---

## 📱 Features

1. **Components Gallery**:
   - Interactive tactile buttons with physical spring transitions and haptics.
   - Form controls: switches with glow options, sliders with discrete step haptics, checkboxes, radio groups, and inset text fields.
   - Determinate and indeterminate progress indicators and circular progress arcs.
2. **Live Lighting Lab**:
   - Interactive $360^\circ$ light angle dial.
   - Real-time sliders for depth, distance, and contrast intensity.
   - Pre-configured color palettes: Soft Gray (`#E0E5EC`), Warm Clay (`#E4DCD3`), Lavender Mist (`#E2E2F0`), Dark Slate (`#24272C`), and Midnight (`#191B1F`).
3. **Smart Home Dashboard**:
   - Complete sample production UI containing energy metric cards, climate control circular dials, and ambient media player controls.

flutter run -d macos
